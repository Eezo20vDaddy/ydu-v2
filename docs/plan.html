YDU PARTS — Ground-Up Rebuild

ydu.com.au · VW, Audi & VAG specialists · New custom theme + fitment plugin, zero reuse of KarPart / Elementor / Slider Revolution

Hybrid WP theme WooCommerce 10.x ydu-fitment plugin Side-by-side until approved < 500 products
Data-safety guarantee: production catalog, orders and customers are never edited or deleted by any task. All build & testing happens on a parallel staging clone. Launch installs the finished theme/plugin onto production — the staging database is never copied over the live store, so orders taken during the evaluation period are safe.

Architecture

  • Hybrid theme: classic PHP + theme.json + block cart/checkout
  • Vehicle finder lives in its own plugin — survives future theme swaps
  • Hierarchical vehicle taxonomy: Make > Model > Submodel > Variant
  • REST fitment/v1 endpoints + Interactivity API dropdowns
  • Static hero replaces Slider Revolution

Kept / Dropped

  • Kept: WooCommerce + WooPayments, WPClever wishlist / compare / quick view, LiteSpeed Cache, Google Listings & Ads
  • Dropped: KarPart theme + child, Elementor, Slider Revolution
  • Parity: all attributes, vehicle data, pages, SEO URLs
